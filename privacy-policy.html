📡 VerifiedPulse

Privacy Policy

Last updated: August 23, 2026

🔒 Introduction

This Privacy Policy describes how VerifiedPulse ("we", "our", or "the application") handles information when you use our fact-checking service. VerifiedPulse evaluates claims using propositional logic and live web search evidence. We are committed to protecting your privacy and handling any data in accordance with applicable laws.

📝 Information We Collect

User Input: Claims submitted by you through the frontend interface are sent to our backend server for processing.

Server Logs: Standard server logs may record IP addresses, timestamps, and request metadata for security and debugging purposes.

LLM API Requests: Claims and proposition data are sent to a configurable LLM provider (e.g., OpenAI, Anthropic) for structured analysis. No personal identifiers are attached to these requests unless you voluntarily include them in your input.

Stored Records: When you run a fact check, the claim text, any propositions you provide, the computed verification result, and the retrieved search evidence are saved in our database (local SQLite by default, or Supabase if configured). The service has no user registration or login, so these records are not linked to any account. Because claim text is stored as-submitted, it may contain personal information if you choose to include it.

📦 How We Use Information

We use collected information exclusively to:

  • Retrieve web search evidence to corroborate or contradict claims.
  • Apply propositional logic to evaluate claims for verification status.
  • Store claim text, propositions, verification results, and search evidence in a local SQLite database (or Supabase if configured) to generate aggregate metrics.
  • Improve the reliability and accuracy of the fact-checking engine.

We do not use collected data for advertising, profiling, or any commercial purpose outside of the described functionality.

💡 Web Search & Third-Party Services

VerifiedPulse integrates with the following third-party services:

  • DuckDuckGo — used for web search evidence (default, no API key required). Subject to DuckDuckGo's privacy policy.
  • LLM Providers (e.g., OpenAI, Anthropic) — subject to their respective privacy policies. Only claim text and analysis prompts are transmitted; no PII is included unless you provide it.
  • Optional Search APIs (e.g., Tavily, Serper) — if configured via environment variables, used instead of DuckDuckGo for web search evidence. Subject to their respective privacy policies.

🔐 Security

We implement reasonable technical measures to protect data, including encrypted API communications (HTTPS), environment-variable-based credential storage, and local database access controls. However, no system is completely secure, and we cannot guarantee absolute security of data transmitted over the internet.

⏱ Data Retention & Your Choices

Stored fact-check records (claim text, propositions, results, and search evidence) are retained in the database to power the metrics dashboard and improve the engine. You may request deletion of specific records or all data you have submitted by contacting the app administrator.

If you do not want your claim text transmitted to third-party LLM or search providers, avoid entering personal or sensitive information, or run the service in its offline heuristic mode (which requires no API key and keeps processing local).

🚘 Children's Privacy

VerifiedPulse is not directed at children under the age of 13. We do not knowingly collect personal information from children. If you believe a child has provided us with personal information, please contact us so we can delete it.

📥 Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date. Continued use of VerifiedPulse after changes constitutes acceptance of the updated policy.

📧 Contact

If you have questions about this Privacy Policy, data handling, or wish to request data deletion, please contact the app administrator.
